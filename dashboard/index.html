How the model works

Every row is scored by one function, from the snapshot's own figures only — no name is ever special-cased:

implied = TVL × 0.10 × max(0.15, 1 + clamp(7d %, −80, +300) / 100 × 1.5) × (0.7 + min(age, 1460) / 1460 × 0.9) × bonus

Bonus is 1.35 for a breakout (7d ≥ +25%), 1.15 while heating (≥ +5%), 1.00 while steady, 0.85 while cooling (< −5%) and 0.70 while fading (< −25%). Age is days since DefiLlama began tracking the protocol; unknown age counts as 365 days. The board covers the whole 40-protocol watchlist plus every rankable pre-token protocol below the $50M floor — the early set where the breakouts live. The watchlist's own median 7-day change is : the floor is cooling while the early set moves.

A protocol is listed as pre-token when its record carries no token (no market cap, no CoinGecko id, no symbol). That is what the record says, never proof it has none. Implied value is this radar's own claim about what a token would be worth if the protocol's record stayed as it is; it does not predict whether or when a token is issued.
